# dsh-chat-music（DeepSeek 唱片机）

DSH 的浮窗音乐播放器：**把装有音乐的文件夹拖进「导入区域」就能播放**。

## 界面

```
┌─────────────────────────────────┐
│ ♪ DeepSeek 唱片机    12 首   ▾  │ ← 按住这一条拖动整个浮窗
├─────────────────────────────────┤
│ ▁▃▂▅▇▅▃▁▂▄▆▃▂▁▃▅▇▆▄▂▁▃▅▂▁        │ ← 音频可视化（实时频谱）
│ 歌名                            │
│ 3 / 12 · 播放中                  │
│       ⏮    ( ▶ )    ⏭          │ ← 暂停键：鲜蓝圆底、纯白图标
│ ────────●────────────────────── │ ← 进度条：拖动定位
│ 1:23                     3:45   │
│ ┌─────────────────────────────┐ │
│ │ ＋ 把另一个文件夹拖到这里      │ │
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```

- **拖动**：按住标题条移动；位置记在 `localStorage`，下次打开还在原处。
- **收起**：标题条右侧的 `▾`，收起后只剩标题条（仍可拖动、仍可接收拖放）。
- **导入**：把文件夹（或若干音频文件）拖到浮窗任意位置；递归读取子目录，按文件名排序。
  **重复曲名不追加**：已经在列表里的曲目优先保留，新导入的同名项直接丢弃（并释放其 object URL），
  只把真正新的曲目加进来；面板会提示「新增 N 首，跳过 M 首重复（保留原有的）」。
- **上一首 / 下一首**：暂停键两侧；播放到结尾按当前播放模式继续。
- **进度条**：拖动即定位（`input[type=range]` → `audio.currentTime`）。
- **可视化**：`AudioContext` + `AnalyserNode` 取频谱画柱状图；暂停时缓慢衰减。
- **播放设置**（进度条下方左侧，上下两个滑块的图标）：展开三段滑块
  `单曲循环 / 列表循环 / 随机播放`，决定一首放完后怎么走；选择会记在 `localStorage`。
- **背景设置**（进度条下方右侧，照片图标）：展开两段滑块
  `全歌背景 / 单独背景`：
  - **全歌背景**：所有曲目共用一张图，`选择全歌背景图…` 一次即可；
  - **单独背景**：每首歌各设一张（按曲名记录，`为本曲选择背景图…`），没设置的曲目保持纯色。
  - 选好的图片会压到最长边 1400px 的 JPEG 存进 `localStorage`，刷新后仍在。
- **可视化颜色**（同在背景设置面板里，背景图下面）：
  - `全曲颜色 / 单曲颜色` 两段滑块；
  - 全曲颜色：所有曲目共用一种颜色；单曲颜色：每首各设一种（未设置的曲目回退到全曲颜色）；
  - 颜色选取用原生取色器，选完立刻反映到频谱柱子上；
  - 存 `localStorage`：`dsh-chat-music:color:global`、`dsh-chat-music:color:tracks`、`dsh-chat-music:color-mode`。

## 支持格式

`mp3 / m4a / aac / wav / flac / ogg / oga / opus / weba / wma`（按扩展名或 `audio/*` 判断）。
实际能否解码取决于 Chromium 自带解码器——例如 `.wma` 通常不支持。

## 隐私

文件只用 `URL.createObjectURL` 在本地读取，**不会上传**、不会写入 DSH 会话或磁盘。
刷新页面后播放列表清空（object URL 随页面销毁），需要重新拖入。

## 安装

1. 把本仓库放到任意本地目录；
2. DSH → **插件** → **添加插件** → 选择该目录；
3. 无需构建：`package.json` 已声明 `dsh.bundle.patch` 与 `dsh.client`。

## 限制

- 文件夹拖放依赖 Chromium 的 `DataTransferItem.webkitGetAsEntry()`（桌面版 DSH 可用）。
- 首次播放需要一次用户手势（点暂停键），否则浏览器可能拦截自动播放。
- 可视化只在点击过播放键、建立音频图之后才有数据；纯拖放自动播放时是空频谱。
- 面板固定在 `shell.overlay` 浮层（全窗口最上层），可能遮住其它内容，可收起或拖走。
- 诊断：客户端异常会 `POST /dsh-chat-music/api`，写入 `<DSH_HOME>/chat-music/client-errors.log`。
